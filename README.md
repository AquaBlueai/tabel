# Табель — ходимлар келди-кетди ҳисоби

HR учун веб-панель + ходимлар учун Telegram Mini App. Битта Node.js сервер, SQLite база.

## Имкониятлар

**Ходим (Telegram Mini App)**
- Ботдаги «Табель» тугмаси орқали очилади, Telegram ҳисоби орқали автоматик аниқланади (initData имзоси серверда текширилади)
- Биринчи киришда рўйхатдан ўтади → HR тасдиқлайди
- «✅ Келдим» / «🏁 Кетдим» тугмалари, бугунги вақт ва ишланган соат
- Ойлик календарь: ишланган соатлар, кечикишлар, таътил ва ҳ.к.
- Офис геолокацияси ёқилса — фақат офис радиуси ичида белгилаш мумкин

**HR (веб-панель, `/admin/`)**
- «Бугун»: ким келди, кечикди, кетди, келмади — реал вақтда
- «Табель»: ойлик жадвал (ходим × кун), ҳар катакни босиб вақтни тузатиш ёки белги қўйиш
  (Т — таътил, КВ — касаллик, ХС — хизмат сафари, Р — рухсат, С — сабабсиз), сана оралиғи билан
- Excel (.xlsx) га юклаб олиш — рангли, жами кун/соат/кечикиш билан
- Ходимлар: тасдиқлаш, таҳрирлаш, «бўшаган» ҳолати
- Созламалар: иш вақти, кечикиш чегараси, дам олиш ва байрам кунлари, офис координаталари

## Ишга тушириш

```bash
npm install
cp .env.example .env     # ва қийматларни тўлдиринг
npm start
```

- HR панели: `http://localhost:3000/admin/`
- Mini App: `http://localhost:3000/app/`

Локал синов учун `.env` да `DEV_TELEGRAM_ID=111` қўйсангиз, `/app/` ни оддий браузерда очиш мумкин.

## Telegram ботни улаш

1. @BotFather → `/newbot` → токенни `BOT_TOKEN` га ёзинг.
2. Серверни HTTPS домен остида жойлаштиринг ва `WEBAPP_URL` га ёзинг
   (синов учун: `cloudflared tunnel --url http://localhost:3000` ёки `ngrok http 3000`).
3. Серверни қайта ишга туширинг — бот менюсига «Табель» тугмаси автоматик қўйилади.
4. Ходимлар ботга `/start` ёзади → тугмани босади → рўйхатдан ўтади → HR тасдиқлайди.

## Docker

```bash
docker build -t tabel .
docker run -d --env-file .env -p 3000:3000 -v tabel-data:/app/data tabel
```

## Тузилма

```
src/server.js     — API (ходим + HR)
src/db.js         — SQLite схемаси ва созламалар
src/auth.js       — HR сессияси, Telegram initData текшируви
src/timesheet.js  — табель ҳисоби ва Excel экспорт
src/bot.js        — Telegram бот (long polling)
public/admin/     — HR веб-панели
public/app/       — Telegram Mini App
```

Node.js 22.13+ талаб қилинади (ички `node:sqlite` ишлатилади).
